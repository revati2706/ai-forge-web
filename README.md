# ⚙️ AI Forge  

> a small place where I tried to make characters feel a little alive.  

---

## 🌌 About  

AI Forge is a full stack project I built while learning and experimenting with AI and web development.  
It’s kind of like a smaller version of Character AI — you can **create your own personas**, **chat with them**, **delete messages**, and **search through them**.  

It’s not perfect, I know that — but it’s real.  
Every part of it was made with patience, curiosity, and a lot of trial and error.  

---

## 🧩 Features  

- 💬 Chat with custom characters  
- 🎭 Create and edit your own personas  
- 🔍 Search through personas or messages  
- 🗑️ Delete specific texts  
- 🌗 Clean and simple UI made with Tailwind CSS  
- ⚙️ Backend connected with Gemini API  

---

## 🧠 Tech Stack  

**Frontend:** React, Zustand, Tailwind CSS  
**Backend:** Node.js, Express, Axios  
**AI:** Gemini API  

---

## 🚀 Getting Started  

### 1. Clone the Repository  
```bash
git clone https://github.com/<your-username>/ai-forge.git
cd ai-forge


2. Setup Backend
cd backend
npm install

Create a file named .env inside the backend folder:

GEMINI_API_KEY=your_api_key_here
PORT=5000


Run the backend server:

npm run dev

3. Setup Frontend
cd ../frontend
npm install
npm start


Once it starts, open the link shown in your terminal (usually http://localhost:5173
).
